      MFPCA 音響最適化システム - 要件定義書

      1. システム概要

      1.1 目的

      多変量関数主成分分析（MFPCA）を用いて、音響波形を因子で制御し、目標波形への最適化を行うインタラクティブシステム。

      1.2 主要機能

      • データ分析: MFPCA による多変量時系列データの次元削減
      • 予測モデリング: 3種類の機械学習モデルによる因子→主成分の予測
      • インタラクティブ調整: リアルタイムで因子を調整し波形を比較
      • 最適化探索: 2種類のアルゴリズムで目標波形に最も近い因子を探索
      • 感度分析: 因子変動に対する波形の感度を可視化

      2. データ構造

      2.1 基本パラメータ

      パラメータ 値 説明
      条件数 (N_cond) 60 実験条件の総数
      マイク数 (n_mic) 6 計測マイクロフォンの数
      時間点数 (n_time) 100 各波形のサンプリング点数
      因子数 3 制御因子（F1, F2, F3）
      主成分数 (M) 4 MFPCAで抽出する主成分数

      2.2 データ生成

      # 因子データ
factors: data.frame (60 × 4)
  - cond: 条件ID (1-60)
  - F1, F2, F3: 各因子の値 [-1, 1]

# 波形データ
Y_array: array (60 × 100 × 6)
  - dim1: 条件
  - dim2: 時間点
  - dim3: マイク

# 生成モデル
signal_ij = base_wave + F1*β1*shape1 + F2*β2*shape2 + F3*β3*shape3 + noise

      2.3 ベータ行列（真の係数）

      beta_matrix: matrix (6 × 3)
  Mic1: [0.8, 0.4, 0.2]
  Mic2: [0.6, 0.2, 0.3]
  Mic3: [0.3, 0.7, 0.2]
  Mic4: [0.1, 0.5, 0.6]
  Mic5: [0.4, 0.1, 0.7]
  Mic6: [0.2, 0.3, 0.5]

      2.4 形状関数

      shape_F1 = sin(4π * time_grid)
shape_F2 = (time_grid - 0.5)
shape_F3 = (1 - (time_grid - 0.5)²)

      3.2 開発環境

      • R version: 4.0 以上推奨
      • RStudio: 推奨（必須ではない）
      • メモリ: 最低 4GB RAM
      • ブラウザ: Chrome, Firefox, Safari, Edge（最新版）

      4. 機能要件

      4.1 タブ1: 概要とMFPCA結果

      4.1.1 MFPCA分散説明率プロット

      • 入力: mfpca_res$values
      • 出力:
        • 棒グラフ: 各主成分の個別寄与率
        • 折れ線グラフ: 累積寄与率
      • 可視化:
        • X軸: 主成分 (PC1-PC4)
        • Y軸: 寄与率 (0-100%)

      4.1.2 因子寄与ヒートマップ

      • 入力: 標準化回帰係数 (coef_df)
      • 出力: 3因子 × 4主成分のヒートマップ
      • カラースケール: 青（負）→ 白（0）→ 赤（正）

      4.1.3 因子総合寄与度

      • 計算: 各因子の係数二乗和 sum(Beta²)
      • 出力: 横棒グラフ
      • ソート: 寄与度降順

      4.1.4 データ情報

      • 条件数、マイク数、時間点数
      • 主成分数
      • 累積寄与率

      4.2 タブ2: モデル選択と評価

      4.2.1 予測モデル

      3種類のモデルで 因子(F1, F2, F3) → PCスコア(PC1-PC4) を予測

      モデル 種類 特徴
      重回帰分析 (lm) 線形 解釈性高、計算高速
      ランダムフォレスト (rf) 非線形 ロバスト、変数重要度
      ガウス過程 (gp) 確率的非線形 不確実性定量化、滑らか

      4.2.2 データ分割

      • 訓練データ: 80% (48条件)
      • テストデータ: 20% (12条件)
      • シード: 456 (再現性担保)

      4.2.3 モデル訓練設定

      重回帰分析 (lm):

      PC_i ~ F1 + F2 + F3
方法: 最小二乗法

      ランダムフォレスト (rf):

      ntree = 500
importance = TRUE

      ガウス過程 (gp):

      カーネル: Matern 5/2
平均関数: 定数

      4.2.4 評価指標

      • R² (決定係数): 予測精度 (0-1, 高いほど良い)
      • RMSE (二乗平均平方根誤差): 予測誤差
      • MAE (平均絶対誤差): 予測誤差

      4.2.5 変数重要度

      モデル 手法 意味
      lm 係数の絶対値 因子の直接的影響度
      rf %IncMSE 変数除去時の精度低下
      gp SHAP値 各予測への平均的貢献度

      4.3 タブ3: 因子調整と最適化

      4.3.1 因子調整（リアルタイム）

      • 入力:
        • スライダー: F1, F2, F3 (範囲: -1 to 1, ステップ: 0.01)
        • 目標条件選択: 1-60
      • 出力:
        • 現在の波形生成
        • 目標波形との差異メトリクス

      4.3.2 差異メトリクス

      1. MSE (平均二乗誤差)

        MSE = mean((current_wave - target_wave)²)

      2. RMSE (二乗平均平方根誤差)

        RMSE = sqrt(MSE)

      3. 平均相関係数

        mean_cor = mean(cor_per_mic)

      4. マイクごとのRMSE

        • 6マイク別々に計算
        • カラーマップ: 相関係数で色分け

      4.3.3 波形比較プロット

      • 表示波形:
        • 目標波形（黒・実線）
        • 現在の波形（赤・破線）
        • 最適化波形（緑・一点鎖線）※最適化実行後
      • レイアウト: 2列 × 3行（6マイク）
      • Y軸: 各マイク独立スケール

      4.3.4 最適化探索

      アルゴリズム選択

      1. L-BFGS-B（勾配ベース）

        • 方法: Limited-memory BFGS with Box constraints
        • 特徴: 高速、局所最適
        • 適用: 滑らかな目的関数

      2. ベイズ最適化（サンプルベース）

        • 方法: Gaussian Process + UCB獲得関数
        • パラメータ:
          • 初期サンプル: 5点
          • イテレーション: 20回
          • kappa: 2.576
        • 特徴: グローバル最適、効率的
      目的関数選択

      1. 直接法（波形ベース）

        minimize: MSE(predicted_wave, target_wave)

      2. モデルベース（PCスコア）

        minimize: MSE(predicted_PC_scores, target_PC_scores)
      最適化結果表示
      • 最適因子値 (F1, F2, F3)
      • 使用アルゴリズム
      • 目的関数タイプ
      • 使用モデル（モデルベースの場合）
      • MSE/RMSE

      4.4 タブ4: 感度分析

      4.4.1 因子変動感度プロット

      • 方法: 各因子を±30%変動させてRMSE計算
      • サンプル点: 21点 (±30%を5%刻み)
      • X軸: 因子変化率 (%)
      • Y軸: RMSE（目標波形との誤差）
      • 線: 3因子別々にプロット

      4.4.2 因子許容範囲テーブル

      • 現在値
      • 推奨範囲 (±10%)
      • 感度レベル（高/中/低）

      5. データフロー

      5.1 アプリ起動時

      1. データ生成（60条件 × 6マイク × 100時間点）
2. MFPCA実行 → 4主成分抽出
3. データ分割（80/20）
4. モデル訓練（lm, rf, gp）
5. モデル評価（train/test）
6. UI表示

      5.2 ユーザー操作フロー

      モデル評価フロー

      ユーザー: モデル選択（lm/rf/gp）

      因子調整フロー

    ↓
システム: calculate_metrics(current, target)
    ↓
システム: プロット更新（リアルタイム）

      最適化フロー

      ユーザー: 目標条件選択
    ↓

    ↓
ユーザー: 目的関数選択（direct/model）
    ↓
ユーザー: 最適化実行ボタン
    ↓
システム: 最適化計算（進捗表示）
    ↓
システム: 結果表示
    ↓
ユーザー: 結果適用（オプション）
    ↓
システム: スライダー更新 → 波形更新

      7. パフォーマンス要件

      7.1 応答時間

      操作 目標時間
      スライダー調整 < 100ms
      プロット更新 < 500ms
      モデル切替 < 1s
      L-BFGS-B最適化 < 5s
      ベイズ最適化 < 30s
      SHAP値計算（GP） < 10s

      7.2 メモリ使用量

      • ベース: ~500MB（データ読込後）
      • ピーク: ~1.5GB（最適化実行時）

      12. 付録

      12.1 主要関数一覧

      関数名 用途 入力 出力
      generate_waveform() 波形生成 F1, F2, F3 波形行列 (100×6)
      calculate_pc_scores() PCスコア計算 波形行列 PCスコアベクトル (4)
      calculate_metrics() 差異計算 2つの波形 メトリクスリスト
      optimize_factors_direct() 直接最適化 目標波形 最適因子
      optimize_factors_model() モデル最適化 目標PC, モデル 最適因子

      evaluate_model() モデル評価 モデル, データ 評価指標

      12.2 グローバル変数

      変数名 型 サイズ 説明
      Y_array array 60×100×6 全波形データ
      factors data.frame 60×4 因子データ
      all_pc_scores matrix 60×4 全PCスコア
      beta_matrix matrix 6×3 真の係数
      lm_models list 4要素 線形モデル
      rf_models list 4要素 RFモデル
      gp_models list 4要素 GPモデル
      train_data data.frame 48×7 訓練データ
